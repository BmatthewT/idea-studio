# Idea Studio

Direction selected by the agent under the user's explicit instruction to choose the style.

A modern black workspace, requested by the user in the second revision. Pure black (#000000), charcoal panels (#101114), raised inputs (#181A1E), and near-white text (#F2F3F5) establish clear surface hierarchy. Lime (#B6F36A) identifies the primary action, active step, selection, and focus. Segoe UI semibold headings and compact controls give the native Windows app a contemporary rhythm. Consolas remains reserved for editable Markdown. Corners range from 7px controls to 12px workspace panels; there are no gradients or decorative glow.

ENERGY 1 / RHYTHM 2 / MOTION 1. No decorative animation. A fixed sequence provides orientation; the interior changes from idea entry to structured questions, reference selection, and documents. The dominant heading tells the user what decision to make next. Thin rules divide reference choices and document sections. Color swatches communicate palette choices rather than invented product screenshots. External-link arrows identify browser actions.

The app uses native WPF inputs with dark templates, labels, keyboard focus, scrollable content, validation messages, cancellation, and file dialogs. The title bar requests the Windows dark appearance. Platform choices are visible radio buttons. It supports one dark theme and a minimum desktop window size. Exported documents retain their existing styling for sharing and printing.
